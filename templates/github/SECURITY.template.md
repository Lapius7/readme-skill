# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| LATEST_MINOR.x | Yes |
| Older | No |

## Reporting a vulnerability

Please do not open a public issue for a security problem.
Report it privately through [GitHub's private vulnerability reporting](https://github.com/OWNER/REPO/security/advisories/new).

Include the affected version, the steps to reproduce, and the impact you expect.
You can expect a first reply within a week.
