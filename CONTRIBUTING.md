# Contributing

Thanks for your interest in README Creator SKILL.

## Reporting a problem or an idea

- Search [existing issues](https://github.com/Lapius7/readme-skill/issues) first.
- For a bug, include the version, your environment, and the steps to reproduce.
- For a security problem, follow [SECURITY.md](SECURITY.md) instead of opening an issue.

## Pull requests

1. Open an issue first for anything larger than a small fix.
2. Keep each pull request to one change.
3. Run the check below before you push.

## Check

```sh
python3 scripts/audit-repo.py .
```
