# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| Latest on main | Yes |
| Older | No |

## Reporting a vulnerability

Please do not open a public issue for a security problem.
Report it privately through [GitHub's private vulnerability reporting](https://github.com/Lapius7/readme-skill/security/advisories/new).

Include the affected version, the steps to reproduce, and the impact you expect.
You can expect a first reply within a week.
